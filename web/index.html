What a stamp says

A stamp says this text was typed key by key on the NTK keyboard by someone whose typing matches this NEAR account's fingerprint, not that it was written without help.

The NTK keyboard measures how a person types and sends the measurements, sealed, into an enclave on NEAR OutLayer. The enclave keeps a typing fingerprint per NEAR account and signs a stamp when new typing matches it. This page checks the stamp's signature against the enclave's pinned key, and the text before the tag against the stamp.
