Install NTK on Android

The NTK keyboard for Android phones, signed by the project. It runs on NEAR testnet only, so no real money is involved. Version 0.2, 1.0 MB, Android 7 or newer (tested on Android 16).

Set it up

  1. Open the downloaded file. Android asks whether your browser may install apps: allow it, then install.
  2. Open NTK. Tap Turn on NTK in system settings, switch NTK on, then tap Switch to the NTK keyboard.
  3. Tap Log in with a NEAR wallet and approve one transaction in Meteor or Intear (a NEAR testnet account with a little test NEAR). It adds a key that can only sign NTK requests. Or let NTK create a testnet account for you.
  4. Tap Enroll and type the three short texts. NTK learns how you type; the fingerprint is sealed in the enclave.
  5. Type anywhere. When you have typed at least 40 keys, tap sign on the keyboard's strip. On a match the keyboard adds a tag like [NTK <id>] after your text.
  6. Optional, stamp buttons in any app: in NTK's setup, open the stamp-button step and switch NTK stamp buttons on under Accessibility. If Android says "Restricted setting", open Settings, Apps, NTK, the menu at the top right, Allow restricted settings, and switch it on again.

Anyone can check a stamp at ntk.tools, with or without the app. What the keyboard measures and sends is on the privacy page.

Source

The app is built from github.com/sgraphics/nearthekeyboard (the android/ folder, built on Simple Keyboard). Calls cost the project a little test money and are rate limited.
